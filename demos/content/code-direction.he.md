הדף הזה בעברית, ולכן כולו מימין לשמאל. הקוד בו נשאר משמאל לימין בלי שכתבתי
דבר: הפקודה `git commit -m "fix"` נקראת כמו שהיא, וגם ההשוואה `a < b` לא
מתהפכת.

```python,title=fib.py,linenos
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

גם המספרים והסוגריים בקוד נשארים במקומם: `f(1, 2) -> [3]`.
